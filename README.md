# Wellness with Bre

Interactive workout companion SPA built with Vite, React, and Tailwind CSS.

## Features

- Daily workout schedule
- YouTube workout companion with play/pause and timestamp navigation
- Exercise logging persisted in local storage

## Commands

| Command | Purpose |
|---------|---------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run test:e2e` | Playwright end-to-end tests |

## Development

```bash
npm install
npm run dev
```

Append `?real-youtube=1` to a workout URL to use the live YouTube iframe player instead of the built-in mock player.
